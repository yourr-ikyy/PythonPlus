06 / FAQ & quick help

Useful truths before you start tinkering.

Is this a real Python interpreter?

Yes. It loads Pyodide, which runs Python compiled to WebAssembly in your browser. It is not just a JavaScript imitation. Some native extensions and packages that require OS access may not work.

Can I use it completely offline?

The page itself is one downloadable HTML file, so the layout, help, and tools are self-contained. Python execution needs the Pyodide JavaScript/WASM runtime to have loaded. This file does not embed those larger runtime assets, so an offline first launch may fail unless the runtime is available from cache.

What does the error highlight actually show?

When Pyodide gives a traceback with a source line, PyPlay+ highlights that line number and the editor row, then gives a simplified explanation. Some errors inside library code or native modules may not map to a line in your own code.

Why does input() open a dialog?

PyPlay+ connects Python's standard input to a browser prompt. Enter a value there when your code requests input. For programs that request several inputs, the prompt appears for each call.

How do I download my program?

Use “Download .py” to save the current editor contents as a Python file, “.txt” to save the output log, or “Download HTML” to save a standalone copy of this app page.

Does Download .py create an EXE?

No. It downloads the source code. To create a Windows executable, you would use a packaging tool such as PyInstaller on a computer with Python installed. The resulting EXE is a separate build.

Why might import fail?

Pyodide provides many Python standard-library modules and selected packages, but it cannot run every package that depends on native OS APIs or desktop access. Browser sandbox restrictions also apply.

Can I use this for passwords or private files?

Do not paste secrets into code you plan to share. Code runs locally in the browser session, but imported packages, browser capabilities, or code you choose to run can still access data available to that environment. Review code before running it.
